# 📁 Smart File Organizer (Dockerized)

Un script automatizado en Python empaquetado en Docker para clasificar y organizar archivos desordenados por categoría (Documentos, Imágenes, Código, etc.).

## 🚀 Uso Rápido

### Prerrequisitos
* [Docker](https://www.docker.com/) y Docker Compose instalados.

### Pasos
1. Clona el repositorio:
   ```bash
   git clone [https://github.com/tu-usuario/file-organizer-docker.git](https://github.com/tu-usuario/file-organizer-docker.git)
   cd file-organizer-docker
   ```
2. Coloca los archivos que deseas organizar dentro de la carpeta `downloads/`.
3. Ejecuta el contenedor:
   ```bash
   docker compose up --build
   ```

## 🛠️ Tecnologías
* Python 3.11
* Docker & Docker Compose
